Web-based-Patient-Medical-Records-and-Appointment-System-for-Doc-Dental-Care

To develop a system that will improve the medical records of Dental Clinic in terms of editing, updating, retrieving and deleting patient records. This system will also have appointment online booking to lessen the phone calls, manual note taking and text messages that the clinic handles. Overall, this system will allow both admin and user to lessen workload and improve efficiency. It will also help avoid redundancy in records and booking of appointments by automatically blocking the same hour on the same day that a patient books.
